# بدربي — Demo

نسخة تجريبية (Demo) من تطبيق **بدربي** لحجز رحلات بين المحافظات بالعراق. كل البيانات تجريبية ومحفوظة بالتلفون — ما اكو سيرفر ولا دفع حقيقي.

## تنزيل التطبيقين

| التطبيق | لمنو | الرابط |
|---|---|---|
| **بدربي** | المسافرين | [⬇️ bdarbi-demo.apk](https://github.com/Aboalhussn/bdarbi-demo/releases/latest/download/bdarbi-demo.apk) |
| **كابتن بدربي** | الكباتن، سواق المكاتب، مكاتب السفر، والإدارة | [⬇️ bdarbi-partner.apk](https://github.com/Aboalhussn/bdarbi-demo/releases/latest/download/bdarbi-partner.apk) |

افتح الرابط من التلفون، نزّل الملف، واسمح بـ «التثبيت من مصادر غير معروفة» إذا طلب. التطبيقين ينزلون سوا على نفس التلفون.
كل ما يترفع تعديل على `main`، GitHub Actions يبني الاثنين ويحطهم بنفس الروابط.

**«كابتن بدربي» يعرف منو انت من رقمك** (أي كلمة سر، والأرقام تنضغط من شاشة الدخول):
- الإدارة: `0711 111 1111` — على الآيباد تطلع بشكل الموقع (قائمة جانبية وشاشات مقسومة)، وعلى التلفون بشكل التطبيق.
- مكتب سفر: `0770 555 1234`
- سائق مكتب: `0770 111 0001`
- أي رقم ثاني: كابتن.

> كل تطبيق يحفظ بياناته بتلفونه (ما اكو سيرفر)، فحجز المسافر ما يوصل لتطبيق الكابتن بتلفون ثاني. مسح الـ QR يشتغل بين التلفونات لأن التذكرة نفسها بيها معلومات الحجز.

## شنو تكدر تجرب

**بدربي (المسافر)**
- يفتح مباشرة على شاشة التحميل (3 ثواني) — شاشة فتح أندرويد تبيّن نفس اللوكو بنفس المكان فتكمل وياها ← تفعيل الموقع والإشعارات ← تسجيل الدخول برقم عراقي (+964) ← رمز التحقق (أي 4 أرقام).
- **البحث:** من / إلى، التاريخ من روزنامة، «مسافر وحده» (مقعد واحد) أو «عائلة» (أكثر من 4)، والنتائج تطلع بنفس صفحة البحث. اكو رحلات من بغداد وإلها.
- اختيار المقاعد (باص / سيارة)، تأكيد الحجز مع كوبون (`WELCOME` أو `EID2026`) أو الدفع ببطاقتك، والتذكرة بيها QR ورمز من 6 خانات، وزر «تنزيل صورة التكت» يحفظ صورة التذكرة كاملة بالمعرض (Pictures/Bdarbi).
- **الفنادق:** تختار يوم الوصول والمغادرة من روزنامة، والأيام بينهم تتلوّن. الحجز مباشرة ويا الفندق بالواتساب أو الاتصال.
- **الإشعارات:** جرس بالرئيسية — تأكيد الحجز، تأخير، انطلاق، وصول، إلغاء.
- **تقييم الرحلة:** بعد الوصول — نجوم وملاحظات سريعة وتعليق (+20 نقطة).
- **تتبع الباص:** من التذكرة — قبل الانطلاق يبين وين الباص وبعد شكد يوصل الكراج، وبعد الانطلاق يرسم الطريق لنقطة الانتهاء والباص يتحرك عليه (وبيه عرض تجريبي سريع).
- **حسابي:** معلوماتك الشخصية (صورة، اسم، رقم، إيميل، الجنس، وتغيير الرمز بشريط قوة من 4 خطوط)، سياسة الخصوصية والاستخدام و**المحفظة** (تضيف بطاقة — أو تضغط «بطاقة تجريبية» تنملي وحدها — يبين أول 4 أرقام والباقي مخفي — وتشوف عملياتك).
- الكراجات على خرائط Google مع «الاتجاهات» و«مشاركة الموقع»، كوستر خاص، المكافآت، رحلاتي.

**كابتن بدربي — الكابتن**
- **كابتن جديد:** تسجيل بـ 3 خطوات (معلوماته، سيارته بنفس تصميم «سجّل سيارتك» مع لوحة عراقية، وتصوير المستمسكات بالتسلسل: وجه الإجازة ← ظهرها ← وجه السنوية ← ظهرها، والتطبيق يقرأ كل وحدة ويطلب اللي بعدها) وبعدها شاشة «بانتظار موافقة الإدارة» (بالديمو اكو زر يحاكي الموافقة).
- **إدارة الرحلة:** «انطلقنا» / «وصلنا» / «تأخير» / «إلغاء» — المسافر يوصله إشعار، والخريطة تمشي حسب أزرار الكابتن.
- **التقييم:** الكابتن يشوف تقييمه الكلي بس (مو كل تقييم لحاله). التقييم يرتّب نتائج البحث: الكابتن الأعلى تقييماً رحلته تطلع أول.
- **الركاب:** المقاعد وقائمة الركاب، وزر «طلبات الحجز» فوك على اليسار يفتح الطلبات الجديدة (قبول / رفض).
- **الإنجازات:** تحديات بمكافآت تنضاف للمحفظة (مثلاً 3 رحلات خلال يومين = 25,000 د.ع)، وإذا اجه تحدي جديد أو كمّل تحدي يوصله إشعار.
- **ملفي:** معلوماته الشخصية، المحفظة والأرباح (يضيف بطاقته أول، وبعدها تطلع بطاقة بدربي وعليها رصيده ويسحب أرباحه عليها؛ عمولة بدربي 5% على الدفع الإلكتروني بس)، مركبتي والمستمسكات، سياسة الخصوصية، والدعم.
- **مسح التذكرة بالكاميرا** (افتح التذكرة بتلفون ثاني وامسحها)، أو كتابة الرمز يدوياً، مع حالات: صحيحة / صاعد من قبل / رحلة ثانية / ملغية / مو صحيحة.
- **رحلة جديدة (3 خطوات):** ① الانطلاق والوصول وكراج الانطلاق ونقطة الانتهاء ② روحة بس أو روحة ورجعة والسعر ③ موعد الانطلاق وموعد الرجعة. كراج الانطلاق من كراجات المحافظة اللي يطلع منها، المركبة ثابتة من ملفه، اليوم من روزنامة والوقت من ساعة دائرية تسحب عقربها بإصبعك (12 ساعة، ص / م)، يبين وقت الوصول المتوقع، وما يقبل رحلة تتعارض ويا رحلة ثانية عنده.
- **الدعم:** محادثة ويا الدعم للمسافر وللكابتن (قبل تسجيل الخروج).

**كابتن بدربي — مكاتب السفر**
- **الرئيسية:** مبيعات المكتب (اليوم / الأسبوع / الشهر)، حجوزات اليوم ونسبة الإشغال، والرحلات الجاية اليوم.
- **الرحلات:** رحلات اليوم وباجر وشوكت تطلع، وتضغط الرحلة تشوف كل المسافرين المسجلين عليها.
- **+ أضف رحلة:** نفس خطوات الكابتن، بس يختار المركبة والسائق ينحدد منها.
- **الأسطول:** السيارات بلوحاتها، و«أضف سيارة» بنفس شكل «سجّل سيارتك».
- **حسابي:** معلومات المكتب وشعاره، والسواق: يضيف سائق ويسوي حسابه (رقم ورمز). السائق يدخل «كابتن بدربي» برقمه (جرّب 770 111 0001)، ويشوف سيارته والرحلة اللي حددها إله المكتب، ويمسح تذاكر الركاب، وما يگدر ينشئ رحلة.

**كابتن بدربي — الإدارة**
- نظرة عامة، طلبات الانضمام (مستمسكات واللي قرأه التطبيق، قبول أو رفض بسبب — الكابتن اللي يسجّل بنفس التلفون ينقبل من هنا)، الدعم (ترد على المحادثات ويوصل الرد للكابتن أو المكتب)، السحوبات، السفرات (نشر أو رفض)، التحديات (تحدي جديد يوصل إشعاره للكباتن)، والحجوزات والمكاتب والكراجات والفنادق والكوبونات.

**سفرات المكاتب**
- **المكتب:** زر + ← «سفرة سياحية أو زيارة» بـ 4 خطوات: الصور (أولها غلاف) والاسم والنوع ومنين لوين ونقطة التجمع والوصف ← يوم وساعة الذهاب والرجعة (المدة تنحسب وحدها) والمركبة وآخر موعد للحجز ← شنو يشمل (نقل، فندق، فطور، غدا، عشا، مرشد، تذاكر، تأمين) والفندق وخطة الرحلة يوم بيوم (عنوان لكل يوم وفقرات بالوقت) ← أسعار البالغ والطفل والغرفة المنفردة، والعربون، والإلغاء، والمستمسكات. سفراته تطلع بتبويب «السفرات» بالرحلات مع عدد الحجوزات.
- **المسافر:** بصفحة «اختار رحلتك» يختار «سفرات المكاتب»: كارتات بالصورة والمدة والسعر، وصفحة السفرة بالصور، وشنو يشمل (قائمة بالتفاصيل)، وخطة الرحلة يوم بيوم، والشروط. يحجز بعدد البالغين والأطفال، ويدفع العربون بزين كاش أو البطاقة أو كلشي نقداً بالكراج، ويطلعله رمز حجز وQR، وتطلع السفرة برحلاتي.

**الحجز والدفع**
- **أسماء المسافرين:** لكل مقعد اسم وجنس. مقاعد النساء تنقفل على الرجل المسافر وحده، وبحجز العائلة مقعد النساء لازم يكون لامرأة.
- **شاشة الدفع:** زين كاش أو البطاقة تفتح شاشة تحويل وهمية برمز تأكيد من 6 أرقام (3 محاولات)، وبعدها ينحجز. النقد ينحجز مباشرة.
- **أرباح الكابتن:** اليوم / الأسبوع / الشهر، إلكتروني مقابل نقدي، رسم بالأيام، والصافي بعد العمولة.

> بالنسخة النهائية راح يكون تطبيقين منفصلين: «بدربي» للمسافر و«كابتن بدربي» للكباتن.

## التشغيل محلياً

```bash
npm install
npm run dev          # يفتح بالمتصفح
npm run build        # فحص الأنواع + بناء
npx cap sync android # ينسخ البناء لمشروع Android
cd android && ./gradlew assembleDebug   # يحتاج Android SDK + Java 21
```

التقنيات: React 19 + TypeScript + Vite، و Capacitor 7 لـ Android.
