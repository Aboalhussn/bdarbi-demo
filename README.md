# بدربي — Demo

نسخة تجريبية (Demo) من تطبيق **بدربي** لحجز رحلات بين المحافظات بالعراق. كل البيانات تجريبية ومحفوظة بالتلفون — ما اكو سيرفر ولا دفع حقيقي.

## تنزيل الـ APK

**[⬇️ نزّل آخر نسخة](https://github.com/Aboalhussn/bdarbi-demo/releases/latest/download/bdarbi-demo.apk)**

افتح الرابط من التلفون، نزّل الملف، واسمح بـ «التثبيت من مصادر غير معروفة» إذا طلب.
كل ما يترفع تعديل على `main`، GitHub Actions يبني APK جديد ويحطه بنفس الرابط.

## شنو تكدر تجرب

**المسافر**
- يفتح مباشرة على شاشة التحميل (3 ثواني) — شاشة فتح أندرويد تبيّن نفس اللوكو بنفس المكان فتكمل وياها ← تفعيل الموقع والإشعارات ← تسجيل الدخول برقم عراقي (+964) ← رمز التحقق (أي 4 أرقام).
- **البحث:** من / إلى، التاريخ من روزنامة، «مسافر وحده» (مقعد واحد) أو «عائلة» (أكثر من 4)، والنتائج تطلع بنفس صفحة البحث. اكو رحلات من بغداد وإلها.
- اختيار المقاعد (باص / سيارة)، تأكيد الحجز مع كوبون (`WELCOME` أو `EID2026`) أو الدفع ببطاقتك، والتذكرة بيها QR ورمز من 6 خانات، وزر «تنزيل صورة التكت» يحفظ صورة التذكرة كاملة بالمعرض (Pictures/Bdarbi).
- **الفنادق:** تختار يوم الوصول والمغادرة من روزنامة، والأيام بينهم تتلوّن. الحجز مباشرة ويا الفندق بالواتساب أو الاتصال.
- **الإشعارات:** جرس بالرئيسية — تأكيد الحجز، تأخير، انطلاق، وصول، إلغاء.
- **تقييم الرحلة:** بعد الوصول — نجوم وملاحظات سريعة وتعليق (+20 نقطة).
- **تتبع الباص:** من التذكرة — قبل الانطلاق يبين وين الباص وبعد شكد يوصل الكراج، وبعد الانطلاق يرسم الطريق لنقطة الانتهاء والباص يتحرك عليه (وبيه عرض تجريبي سريع).
- **حسابي:** معلوماتك الشخصية (صورة، اسم، رقم، إيميل، الجنس، وتغيير الرمز بشريط قوة من 4 خطوط)، سياسة الخصوصية والاستخدام و**المحفظة** (تضيف بطاقة — أو تضغط «بطاقة تجريبية» تنملي وحدها — يبين أول 4 أرقام والباقي مخفي — وتشوف عملياتك).
- الكراجات على خرائط Google مع «الاتجاهات» و«مشاركة الموقع»، كوستر خاص، المكافآت، رحلاتي.

**كابتن بدربي** (من «دخول الكابتن» أو «جرّب تطبيق كابتن بدربي»)
- **كابتن جديد:** تسجيل بـ 3 خطوات (معلوماته، سيارته بنفس تصميم «سجّل سيارتك» مع لوحة عراقية، وتصوير المستمسكات بالتسلسل: وجه الإجازة ← ظهرها ← وجه السنوية ← ظهرها، والتطبيق يقرأ كل وحدة ويطلب اللي بعدها) وبعدها شاشة «بانتظار موافقة الإدارة» (بالديمو اكو زر يحاكي الموافقة).
- **إدارة الرحلة:** «انطلقنا» / «وصلنا» / «تأخير» / «إلغاء» — المسافر يوصله إشعار، والخريطة تمشي حسب أزرار الكابتن.
- **التقييمات:** تقييم المسافر يطلع بملف الكابتن.
- رحلته الحالية وعدد الصاعدين، قائمة الركاب والمقاعد.
- **مسح التذكرة بالكاميرا** (افتح التذكرة بتلفون ثاني وامسحها)، أو كتابة الرمز يدوياً، مع حالات: صحيحة / صاعد من قبل / رحلة ثانية / ملغية / مو صحيحة.
- **رحلة جديدة (3 خطوات):** ① الانطلاق والوصول وكراج الانطلاق ونقطة الانتهاء ② روحة بس أو روحة ورجعة والسعر ③ موعد الانطلاق وموعد الرجعة. كراج الانطلاق من كراجات المحافظة اللي يطلع منها، المركبة ثابتة من ملفه، اليوم من روزنامة والوقت من ساعة دائرية تسحب عقربها بإصبعك (12 ساعة، ص / م)، يبين وقت الوصول المتوقع، وما يقبل رحلة تتعارض ويا رحلة ثانية عنده.
- الطلبات (قبول / رفض).

> بالنسخة النهائية راح يكون تطبيقين منفصلين: «بدربي» للمسافر و«كابتن بدربي» للكباتن.

## التشغيل محلياً

```bash
npm install
npm run dev          # يفتح بالمتصفح
npm run build        # فحص الأنواع + بناء
npx cap sync android # ينسخ البناء لمشروع Android
cd android && ./gradlew assembleDebug   # يحتاج Android SDK + Java 21
```

التقنيات: React 19 + TypeScript + Vite، و Capacitor 7 لـ Android.
